# File-based examples (.NET 10)

Featured braid examples are single C# files run with `dotnet run` (no `.csproj` per example).

Run one example from the repository root:

```bash
dotnet run examples/single-file/lost-update/lost-update.cs
```

Run all examples:

```bash
bash examples/single-file/run-examples.sh
```

On Windows (PowerShell):

```powershell
powershell -File examples/single-file/run-examples.ps1
```

Walkthroughs live under [docs/examples](../../docs/examples/).
